HR Analytics Dashboard

This project analyzes employee workforce data to uncover key insights into workforce composition, salary distribution, employee demographics, and workforce trends.

Key Insights
👥 1,817 total employees are included in the dataset.
📍 Dhaka has the highest concentration of employees.
💰 Average salary: 59.80K.
🏆 Abdul Malek is the highest-paid employee.
📊 A significant salary gap exists across employees.
📉 Employee count declined in July, indicating a change in workforce size.
🎯 The workforce is primarily concentrated in the 25–44 age group.
👨 Male employees outnumber female employees.
🩸 Positive blood groups are the most common among employees.
💼 Total expenses exceed salary costs, highlighting additional workforce-related expenses.
Project Objective

The goal of this project is to transform raw HR data into meaningful insights that can support workforce planning, compensation analysis, demographic analysis, and data-driven HR decision-making.
